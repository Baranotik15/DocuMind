# Skills Index

Categorized index of the skills in `.claude/skills/`. Each skill contains a
`SKILL.md` with patterns and rules. This is a reusable skeleton — add
project-specific skills as your codebase grows.

## Development Discipline

| Skill | Purpose |
|-------|---------|
| `gather-context/` | Parallel codebase research before starting work |
| `write-plan/` | Bite-sized implementation plans from specs |
| `test-driven-development/` | Red-Green-Refactor cycle for all features and bug fixes |
| `systematic-debugging/` | Four-phase root cause investigation |
| `code-simplifier/` | Post-implementation complexity reduction |
| `thermo-review/` | Extremely strict maintainability audit (giant files, spaghetti growth) |

## Product & Planning

| Skill | Purpose |
|-------|---------|
| `prd-creation/` | Comprehensive PRDs and feature specifications |

## Workflow & Git

| Skill | Purpose |
|-------|---------|
| `commit/` | Commit changes with automated hook validation |
| `push/` | Push and create PR with optional watch mode |
| `fix-pr/` | Fix CI failures and review comments on a PR |
| `review-feedback/` | Iterate on code-review feedback from a PR |

> **Worktrees:** Use `claude --worktree <name>` (hooks in `.claude/hooks/worktree-{create,remove}.sh`)
